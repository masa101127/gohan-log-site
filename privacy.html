ごごはんログ

プライバシーポリシー

最終更新日: 2026年10月22日

ごはんログ（以下「本アプリ」）は、作った料理を写真と音声で記録する iPhone アプリです。本アプリが扱う情報と、その扱い方を説明します。

1. 端末の中にだけ保存する情報

  • 撮影した、または写真ライブラリから選んだ料理の写真
  • 音声入力で喋った内容の文字
  • 料理名・材料・メモ（AI が整えたもの、またはご自身で直したもの）

これらはお使いの iPhone の中にだけ保存します。本アプリの開発者がこれらを受け取ったり、サーバーに保存したりすることはありません。アプリを削除すると、これらの情報も削除されます。

2. 音声の扱い

音声入力の声は、iPhone の中の音声認識（Apple の Speech framework）で文字にします。声そのものを端末の外に送ることはありません。

3. AI に送る情報

初回に同意いただき、AI 整形を購読している場合に限り、喋った内容の文字を、料理名・材料・メモに整えるため、Anthropic 社の AI「Claude」の API に送ります。

  • 送るのは、喋った内容の文字だけです。写真・声・お名前などは送りません
  • 送った文字は、Anthropic 社の規定に従って処理されます。Anthropic 社は、API の入力と出力を受け取ってから30日以内に自動で削除するとしています（利用規約の違反への対応や法令による場合などの例外があります）。また、明示の許可なくモデルの学習に使わないとしています
  • アプリが正規のものであることの確認に、Apple の App Attest を使います。これはアプリと端末の正当性を確かめる仕組みで、お名前などの個人を特定する情報は含みません

同意しなかった場合や、購読していない場合は、AI に何も送らず、喋ったままの文字で記録します。

参考: Anthropic のデータ保持について / API とデータの保持 / Anthropic のプライバシーポリシー

4. 購読と利用回数

  • AI 整形の購読の購入とお支払いは Apple が扱います。本アプリの開発者が、お支払いの情報や Apple アカウントの情報を受け取ることはありません
  • 購読しているかどうかは、アプリが iPhone の中で Apple の仕組み（StoreKit）を使って確かめます
  • AI 整形の月の利用回数は、iPhone の中（キーチェーン）にだけ保存し、外に送りません。この回数は、アプリを削除しても iPhone に残ることがあります。iPhone を初期化すると消えます

5. 本アプリが使う iPhone の機能

  • カメラ: 料理の写真を撮るため
  • マイク・音声認識: 料理の説明を音声で入力し、文字にするため
  • 写真ライブラリ: 撮り忘れた料理の写真を選ぶため

6. トラッキング・広告

本アプリは、広告の表示や、ほかの会社のアプリやウェブサイトをまたいだ追跡（トラッキング）を行いません。利用状況の分析ツールも使っていません。

7. お問い合わせ・改定

本ポリシーについてのお問い合わせは、GitHub の Issues から送ってください。本ポリシーを改定するときは、このページで告知します。
